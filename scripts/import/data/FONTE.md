# Proveniência dos dados

## taco.json

Tabela Brasileira de Composição de Alimentos (TACO), 4ª edição revisada e
ampliada (2011) — NEPA/Unicamp. 597 alimentos, valores por 100 g de parte
comestível. Dados públicos; citar a fonte.

- Original: https://nepa.unicamp.br/publicacoes/tabela-taco/
- JSON derivado: https://github.com/danperrout/tabelataco (public/TACO.json)
- Convenções de valor: `"NA"`/vazio = não disponível (nutriente omitido);
  `"Tr"` = traços (importado como 0); `"*"` = valor não confiável (omitido).
